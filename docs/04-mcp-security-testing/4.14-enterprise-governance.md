# 4.14 Enterprise Governance (`GOV`)

[← Chapter 4 overview](README.md) · [About `docs/tests/`](about-docs-tests.md) · Procedures in [`docs/tests/GOV/`](../tests/GOV/)

## Overview

Governance tests evaluate **organizational controls**: server inventory, approved registries, policy enforcement on hosts, exception handling, and compliance evidence.

## Why this category matters

Enterprises cannot secure MCP by ad hoc installs. Fleet visibility and policy gates determine which procedures in `docs/tests/` are even reachable in production.

## Scope

CMDB/inventory accuracy, allow/block lists, MDM or EDR policy, exception workflows, audit evidence for regulators.

## When to prioritize

Primary for **enterprise platform** teams; complements SUPP and CONF.

## Related categories

[SUPP](4.13-supply-chain.md), [LOG](4.12-logging-detection.md), [PRVC](4.19-privacy-retention.md)

## Common test chains

GOV-02 + SUPP-04; GOV-03 + CONF-02 (policy vs actual exposure).
