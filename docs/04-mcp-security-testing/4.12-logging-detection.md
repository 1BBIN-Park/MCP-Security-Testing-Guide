# 4.12 Logging, Monitoring, and Detection (`LOG`)

[← Chapter 4 overview](README.md) · [About `docs/tests/`](about-docs-tests.md) · Procedures in [`docs/tests/LOG/`](../tests/LOG/)

## Overview

Detection tests ask whether security-relevant MCP events are **logged**, **correlatable**, and **alertable**—tool calls, approvals, injection attempts, and secret exposure.

## Why this category matters

Without structured logs you cannot reconstruct incidents involving model-routed actions or prove control effectiveness to auditors.

## Scope

Tool call audit trails, approval logs, injection detection signals, secret redaction in logs, incident reconstruction queries.

## When to prioritize

Run in parallel with functional tests; validate after finding issues in other categories.

## Related categories

[GOV](4.14-enterprise-governance.md), [SECR](4.17-secrets-credentials.md), [AUTHZ](4.04-authorization-permission.md)

## Common test chains

Any finding in TOOL/AUTHZ/PRMT → LOG-05 (reconstruction); SECR-03 + LOG-04.
