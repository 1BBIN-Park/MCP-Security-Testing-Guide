# 4.16 Gateway, Broker, and Egress Controls (`GW`)

[← Chapter 4 overview](../04-mcp-security-testing.md) · [About `docs/tests/`](about-docs-tests.md) · Procedures in [`docs/tests/GW/`](../tests/GW/)

## Overview

Gateway tests validate **outbound control** for tool-mediated HTTP and other egress: allowlists, SSRF protections, and rate limiting at a central broker.

## Why this category matters

Tools that fetch URLs are SSRF primitives. Without gateway policy, a model can pivot to metadata endpoints, internal admin panels, or cloud credential services.

## Scope

Upstream URL allowlists, DNS rebinding protections, header forwarding rules, throttling and abuse counters at the gateway.

## When to prioritize

Critical when any tool performs **network** calls; defense in depth alongside safe tool code.

[TOOL](4.05-tool-security.md), [INPV](4.10-input-validation.md), [ABUS](4.18-resilience-abuse.md), [TRNS](4.15-transport-channel.md)
