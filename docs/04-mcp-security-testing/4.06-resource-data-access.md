# 4.6 Resource and Data Access (`RSRC`)

[← Chapter 4 overview](../04-mcp-security-testing.md) · [About `docs/tests/`](about-docs-tests.md) · Procedures in [`docs/tests/RSRC/`](../tests/RSRC/)

## Overview

Resources expose **read paths** into files, databases, and documents that become model context. They are a primary channel for data exfiltration and **indirect prompt injection**.

## Why this category matters

Resources feel passive but can leak secrets, enumerate sensitive paths, or carry hidden instructions that override host policy.

## Scope

Resource listing, URI schemes, cross-workspace reads, secret patterns in content, unauthorized file access via resource providers.

## When to prioritize

High when servers expose filesystem, ticket systems, email, or wiki content to the model.

## Related categories

[PRMT](4.07-prompt-instruction.md), [CTX](4.08-context-memory.md), [OUTV](4.11-output-handling.md), [AUTHZ](4.04-authorization-permission.md)

## Common test chains

RSRC-04 (secret leakage) → OUTV-02; RSRC + PRMT-02 (indirect injection through documents).
