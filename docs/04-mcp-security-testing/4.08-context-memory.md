# 4.8 Context and Memory (`CTX`)

[← Chapter 4 overview](../04-mcp-security-testing.md) · [About `docs/tests/`](about-docs-tests.md) · Procedures in [`docs/tests/CTX/`](../tests/CTX/)

## Overview

Context and memory tests examine **what the host remembers**, what it shares across sessions or users, and whether untrusted content can **poison** long-lived state.

## Why this category matters

Memory features amplify injection: a poisoned note in session one can drive tool calls in session two. Multi-tenant hosts must never merge customer context.

## Scope

Session buffers, persistent memory stores, cross-session retrieval, prioritization of untrusted vs system context, sensitive data in context windows.

## When to prioritize

Critical for **multi-user** hosts and products with persistent agent memory.

## Related categories

[PRMT](4.07-prompt-instruction.md), [PRVC](4.19-privacy-retention.md), [AUTHZ](4.04-authorization-permission.md), [AGNT](4.09-agentic-workflow.md)

## Common test chains

CTX-02 (memory poisoning) + AGNT-04 (goal manipulation); CTX-04 + AUTHZ-03.
