# 4.11 Output Handling (`OUTV`)

[← Chapter 4 overview](../04-mcp-security-testing.md) · [About `docs/tests/`](about-docs-tests.md) · Procedures in [`docs/tests/OUTV/`](../tests/OUTV/)

## Overview

Output handling tests verify that **tool and resource results** are safe to render, log, and re-inject into model context—without XSS, secret leakage, or unbounded sensitive data.

## Why this category matters

Hosts display tool output in UI and feed it back to models. Unsafe rendering or verbose errors turn read operations into disclosure channels.

## Scope

HTML/markdown rendering, redaction before display, sensitive fields in structured tool results, output size limits.

## When to prioritize

High for hosts with rich UI and automatic context re-feeding.

## Related categories

[RSRC](4.06-resource-data-access.md), [SECR](4.17-secrets-credentials.md), [PRVC](4.19-privacy-retention.md), [LOG](4.12-logging-detection.md)

## Common test chains

OUTV-02 + RSRC-04; OUTV-01 + PRMT (injection via rendered output).
