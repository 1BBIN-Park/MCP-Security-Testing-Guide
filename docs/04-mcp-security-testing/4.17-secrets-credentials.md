# 4.17 Secrets and Credential Handling (`SECR`)

[← Chapter 4 overview](README.md) · [About `docs/tests/`](about-docs-tests.md) · Procedures in [`docs/tests/SECR/`](../tests/SECR/)

## Overview

Secrets tests examine **where credentials live** (env vars, config files, host keychains), rotation behavior, and whether logs/traces redact sensitive material.

## Why this category matters

MCP servers often load API keys for upstream SaaS. Leakage via env, `.env` files, or verbose logging is a common finding class.

## Scope

Config and env exposure, token caches on the host, rotation/revocation UX, log/trace redaction patterns.

## When to prioritize

Always test when tools call authenticated upstream APIs.

## Related categories

[CONF](4.02-configuration-deployment.md), [LOG](4.12-logging-detection.md), [OUTV](4.11-output-handling.md)

## Common test chains

SECR-01 + CONF-03; SECR-03 + LOG-04.
